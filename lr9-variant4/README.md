## Запуск

```bash
python -m pip install -r requirements.txt
python main.py
```

Графики сохраняются в папку `results/`.  
Код использует фиксированные seed для воспроизводимости генерации тестовых данных. Время выполнения зависит от компьютера и версии Python.

## Структура

- `main.py` — реализация алгоритмов и эксперимент.
- `requirements.txt` — зависимости.
- `diagrams/` — блок-схемы в Mermaid.
- `results/` — графики, создаваемые при запуске.
